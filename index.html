01Where it lives

It speaks up in your pull requests.

When someone adds or changes an AI feature, Throttle tests that job on your own model and leaves a note on the change: what it costs, how your model did, and what happens next.

  • Approve each move, or let passing jobs move on their own.
  • Pin any job to the API. Undo a move any time.

02How it works

Five switches. You flip the first one.

Set it up once. After that, Throttle runs the loop on its own and tells you what it did.

  1. 01OnOffSetup

    Set up once.

    Add the Throttle app to GitHub and change one line so AI calls go through Throttle. About 10 minutes. It runs in your cloud.

  2. 02OnOffWatch

    It watches every change.

    When someone adds, edits or removes an AI feature, Throttle notices on its own.

  3. 03OnOffTest

    It tests before it moves.

    Does your model answer as well as OpenAI or Anthropic, on your real requests? For a new feature with no traffic yet, it writes test questions from the prompt.

  4. 04OnOffFallback

    It never breaks things.

    If your model stumbles, that one request goes to the API on its own. Fallback is always on.

  5. 05OnOffLearn

    It learns from misses.

    Every miss becomes a lesson that trains your model. It handles more jobs each week, and the savings grow.

08Questions

Straight answers.

Something else? Ask Kush.

Does it need access to my code?

It uses a GitHub app that reads the places where your code calls an AI API, so it can find your AI jobs and comment on pull requests. Your prompts and data stay in your cloud.

Where does my model run?

In your own cloud, on GPUs you control. Your prompts and answers never come to us, and Throttle never stores your API keys.

What if my model gets something wrong?

That request goes to OpenAI or Anthropic automatically, so your users still get a good answer. The miss is saved as a lesson that trains your model.

Do I have to approve every move?

You choose. Approve each move yourself, or let jobs that pass move on their own. You can pin any job to the API or undo a move, and every decision is logged.

What does it cost?

The free look costs nothing and moves nothing. After that it is a flat monthly fee that is always smaller than what Throttle saves you. More on pricing.

Which APIs and models does it work with?

OpenAI and Anthropic APIs today. Your own model is an open model served with vLLM, SGLang, Ollama or LMDeploy.

Is Throttle running at real companies yet?

Not yet. Every number on this page is a sample from made-up traffic. We are choosing the first teams to run it with now.

Is it open source?

Yes. The Throttle code is on GitHub under the MIT license.
