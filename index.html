How it works

01 / 05

Capture.

Point your OpenAI or Anthropic calls at Throttle. It logs every request on your own machines and masks personal data before anything is written.

02 / 05

Shadow.

A sample of each kind of request also goes to an open model on your GPUs. Users never see those answers. They only get scored.

03 / 05

Prove.

Your traffic becomes the test. Each kind of request gets a verdict: better, the same, or worse, with error bars. Not a hunch.

04 / 05

Move.

Only the kinds that held up move to your model. If it stumbles, that request goes back to the API on its own.

05 / 05

Refresh.

New open models come out every month. Throttle reruns your tests and tells you when switching wins.

FAQ

Questions.

Does my data leave my machines?

No. Throttle runs on your machines. Your requests only go to the API you already call and to models you run yourself. We never see your prompts or answers.

Which models and servers does it work with?

Open-weight models you run on vLLM, SGLang, Ollama or LMDeploy. You pick the model and the GPUs. Throttle tests it on your own traffic.

What if quality drops?

Then that kind of request stays on the API. If your model has a bad moment later, the request goes to the API on its own. Fallback is automatic.

How are savings measured?

We take what that traffic cost on the API before the move. Then we take what it costs now: your GPU bill plus any calls that fell back to the API. The gap is your savings. Both sides come from your own logs and bills, never from guesses.

What do I need to start?

An app that calls OpenAI or Anthropic. A GPU machine to run an open model on, yours or rented. Then you point your API calls at Throttle, and it starts learning from real traffic.
