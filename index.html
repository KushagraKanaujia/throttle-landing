Every AI job, tested for the way home.

  1. 01

    Set up once.

    Add one line to your code and the GitHub app. Throttle sees every call your app makes to OpenAI or Anthropic. Nothing else changes.

  2. 02

    It watches every change.

    When your team adds or changes an AI feature, Throttle notices in the pull request and picks the job up. No ticket, no project.

  3. 03

    Tests before it moves. Falls back if not.

    Other models, closed or open, answer the same requests in the background, your own model among them. If one does the job as well for less, the job moves. If it ever slips, that request goes straight back to the API.

  4. 04

    Learns from every miss.

    Each miss is saved in your cloud as a lesson for your model. Next month, more of your AI comes home.

  1. 01Re-testing every release costs too much, so it gets skipped.

    “Pin to a specific model version, run evals on every new release, and only upgrade when your test suite passes. But that’s expensive engineering overhead that shouldn’t be necessary.”

    An engineer on Hacker News, Feb 2026 ↗

    ThrottleRuns those tests for you, on a sample of your own traffic, every time a model, a prompt or a price changes.

  2. 02Nobody wants to find out later that the cheaper model was worse.

    “The hard part with these routers is deciding the cheap model is ‘good enough’ without already knowing the answer.”

    An engineer on Hacker News, Jun 2026 ↗

    ThrottleNothing moves until it passes. Each job shows better, same or worse on real requests, with error bars one click away.

  3. 03The model you rent changes under you.

    “Tuesdays behaviour changes by Thursday, 10AMs production isn’t possible at 11:30AM.”

    An engineer on Hacker News, Jun 2026 ↗

    ThrottleRe-runs a job’s tests when the model behind it changes or is retired. A model you own only changes when you say so.

  4. 04The AI bill grows faster than revenue.

    “Our competitors are giving half of their margin over to these large AI service providers”

    A company owner on Hacker News, Jul 2026 ↗

    ThrottleEvery job that passes on a cheaper model, closed or open, comes off the bill. The ledger shows what you kept after GPU costs.

  5. 05One cheap model does most jobs well, and fails a few.

    “Gemini flash was pretty good for my needs (and significantly cheaper), but failed to follow the XML schema in the prompt that Claude could follow.”

    A SaaS developer on Hacker News, May 2025 ↗

    ThrottleDecides job by job, never all at once. Extraction can move while the agent stays where it works.

  6. 06The fallback was there. It didn’t fire.

    “Today gemini was having issues and kept returning 500 errors, but the fallbacks didn’t seem to kick in at all.”

    An engineer in a GitHub issue, Feb 2025 ↗

    ThrottleFallback comes with every move and is always on. Every time it fires, it shows up in the log, so you know it works.

  7. 07Owning GPUs brings its own bills.

    “We’re paying for servers that sit idle at night, you don’t find enough sysadmins”

    An engineer on Hacker News, Apr 2026 ↗

    ThrottleOwning is not always the answer. Throttle counts GPU costs before it calls anything a saving, and when a cheaper API model wins, it says so.

Straight answers.

Something else? Ask Kush.

Does it need access to my code?

It uses a GitHub app that reads where your code calls an AI API. That is how it finds your AI jobs and comments on pull requests. Your prompts and data stay in your cloud.

Where does my model run?

In your own cloud, on GPUs you control. Your prompts and answers never come to us, and Throttle never stores your API keys.

What if my model gets something wrong?

That request goes to OpenAI or Anthropic automatically, so your users still get a good answer. The miss is saved as a lesson that trains your model.

Do I have to approve every move?

You choose. Approve each move yourself, or let jobs that pass move on their own. You can pin any job to the API or undo a move, and every decision is logged.

What does it cost?

The free look costs nothing and moves nothing. After that it is a flat monthly fee that is always smaller than what Throttle saves you. More on pricing.

Which models does it test?

Closed models from OpenAI and Anthropic, and open models you serve yourself with vLLM, SGLang, Ollama or LMDeploy. Every one runs the same tests on the same traffic. Owning a model is the upgrade when it wins.

I already use a gateway or an eval tool. Do I still need this?

Keep them. A gateway carries your requests and an eval tool runs the tests you write. Throttle answers a different question: which model should do each job this week, on your traffic, and it moves the job when the answer changes. See how it compares.

Is Throttle running at real companies yet?

Not yet. Every number on this page is a sample from made-up traffic. We are choosing the first teams to run it with now.

Is it open source?

Yes. The Throttle code is on GitHub under the MIT license.
