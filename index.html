01 / drift

You don’t pay for a config once. You pay for it every hour.

At a fixed hourly GPU price, cost per million tokens rises when tokens per second falls. Every change below moves tokens per second, and most teams check it by eye with a few curl requests before they deploy.

$ / M tokens= GPU $/hour ÷ 3600tokens / second ×1,000,000
  1. --max-num-seqsvLLM flags change how many requests share the GPU at once.
  2. batch sizeBigger batches can raise throughput or queue your users.
  3. modelA new checkpoint or revision generates at a different speed.
  4. quantizationSmaller weights, different kernels, different tokens per second.
  5. GPUA cheaper hourly rate is not a cheaper million tokens by default.
02 / the verdict

Three answers. One of them is “we can’t tell.”

Throttle measures the baseline and the candidate in repeated blocks and puts a 95% interval on each. If the intervals separate, you get a direction. If they overlap, the golden protocol reports it as inconclusive, because a single lucky run on a quiet minute is not a result. throttle check prints CHEAPER / MORE EXPENSIVE / NO WINNER, and NOT CALIBRATED until three repeat checks have measured your machine’s run-to-run noise, because two runs at different times can differ from load alone.

  1. Measure throttle cost against your live endpoint.
  2. Change one thing: a flag, the model, the GPU.
  3. Re-check with throttle plan → smoke → benchmark → golden. Scheduled throttle check runs are in Pro early access.

06 / more levers

Caching and agent profiling. Useful, and off until you ask.

Throttle is a cost meter first. The proxy can also cache and profile, and each lever still ends in the same place: a number you can hold against your bill.

Caching proxy off by default

throttle proxy --enable-cache answers exact repeats from memory with no GPU call. Semantic matching is a separate opt-in (--enable-embeddings), because similar-sounding questions are not always the same question:

"Is it safe to use eval"vs"Is it dangerous to use eval"
embedding similarity0.9874

Opposite meanings, near-identical score. That is why it’s opt-in.

Agent session profiler opt-in

--enable-session-tracking plus throttle sessions splits each agent run into generation time and time spent waiting on tools, estimates how much history is being prefilled again, and names the backend flags to check, like vLLM --enable-prefix-caching.
